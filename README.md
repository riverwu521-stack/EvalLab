# EvalLab · 内容评测工作台

上传评价体系、样本和模型输出，由模型逐条找问题，程序按固定规则算分，生成可复现、可对比的评测报告，并给出提示词优化策略。本地运行，无需安装依赖。

> **这个产品是怎么一步步长出来的？**：现有工具的三个痛点、10 个阶段的迭代、7 个关键里程碑，以及每一次产品拍板背后的原因。建议先读它。

## 为什么做

| 现有做法的问题 | EvalLab 的回答 |
|---|---|
| 评测平台：评价体系必须按固定 Excel 字段填写，只支持 1–5 档，模型选择受限 | 评价体系任意格式，原文完整交给模型；支持扣分型、档位型、判定型三种计分；接入任意 OpenAI 兼容网关 |
| 对话窗口里让模型评：环境不纯净，结果不统一，全是文字 | 每个样本单独调用，评分细则固定；统一的可视化报告，问题在原文中高亮 |
| 评测、优化提示词、再评测的链路接不上 | 提示词版本标签、优化策略、对比历史评测，三步连成闭环 |

## 产品亮点

1. **评价体系来者不拒**：md、json、txt、表格都能传，页面能识别结构就展示指标和权重，识别不了就展示原文；数据源可以缺省。用 13 种写法验证过，没有为任何一份测试样本写死逻辑。
2. **同一把尺子**：评分细则只依据评价体系和数据源制定，生成一次后固定并记录版本号，同一评测集再次评测直接沿用。多轮评测因此可比。
3. **评测、优化、对比的闭环**：评测完成后按根因生成提示词修改方案；改完再测，用同一样本集对比两次结果。详见第五章。
4. **每一步只做自己的事**：评测、复核、问题整合、提示词策略是独立的模型调用，各自的输入输出都写明，一项失败不连累其他项。

## 功能一览

### 1. 新建评测
- **评测类型**：沿用已有类型会带入它的输入结构和评价体系，也可以全新创建。内置「热点简介与创作方向」类型。
- **评价体系**：上传 md、json、txt 或表格文件。结构不规整时，可由模型解析出指标、计分方式和通过规则。
- **输入内容**：导入 `.md`、`.txt`、`.json`、`.jsonl` 文件。数据源可选。样本自动按标题、编号、分隔线、逐行或整篇切分，并按标题或 ID 对齐。这一步不调用模型。
- **被评测的提示词（可选）**：填写提示词原文并打版本标签，报告和历史按标签区分版本。评分本身看不到提示词。
- **模型网关**：在页面里配置网关地址、API Key 和鉴权方式（Bearer、X-Api-Key 或自定义请求头），可测试连接。模型名可搜索或直接填写。
- **运行参数**：并发数（默认 6）、评测样本数、统一评分细则或重新制定、快速模式（不让模型深度思考，约快 4 倍，适合初筛）。
- **运行进度**：「已完成 / 总数」进度条、累计用时、分步状态和日志。可随时停止，已完成的样本会保留。

### 2. 评分
- **三种指标类型**：扣分型（P0 到 P3 按比例扣分）、档位型（模型按评价体系的档位描述选档）、判定型（达标或不达标）。
- **四种通过规则**：总分线、达标项数、平均档位线、单项最低档。结果按原单位展示，例如「4/5 项达标」「3.75 / 5」。
- **统一评分细则**：同一评价体系加同一批数据源只制定一次，带版本号。可手动重新制定，新旧版本对比时会提示尺度不同。

### 3. 评测报告
- **总览**：总分、各评价对象的得分和通过状态、各维度平均分。
- **问题整合**：模型把逐条问题整合为「核心问题到分级子问题」两层，分 P0 到 P3，可展开。
- **复核修正**：有确凿依据的修正由程序核对后执行并重新计分，初评分数保留；拿不准的作为存疑项交给人判断。
- **样本明细**：左边数据源、右边全部输出的两栏版式，问题片段在原文里用颜色标出。
- **提示词优化策略**：先做全局诊断，再按根因给出修改方案和落地顺序。每条诊断标注实际影响面（例如「4/8 条 · P0」）并附上提示词中的原句，建议文本可一键复制。
- **失败重试**：调用失败的样本可在报告里单独重试，完成后重新汇总。

### 4. 历史与对比
- 按时间排列，可按类型筛选，可按总分排序。
- 每张卡片都能「以此类型新建」；评测记录和评价体系都能删除，删除前二次确认。
- **对比历史评测**：同一评测集下对比两次结果，评测集或细则版本不同时弹窗说明。对比页只展示数据，不给结论；细分详情为「数据源 / 某次结果 / 另一次结果」三栏。

### 5. 评价体系
查看每个评测类型绑定的评价体系，按评价对象、指标、权重和直接不通过条件展示，也可以删除。

### 6. 内置内容
附带一次真实的历史评测（热点创作方向第三版，17 个有效样本）及其评价体系和原文，没有配置模型网关也能完整浏览。

### 7. 工程与安全
- 只依赖 Python 3.9 标准库，浏览器里完成全部操作。
- API Key 只保存在本机服务端，不会出现在页面源码或评测报告里。
- 服务只响应本机页面发来的请求。
- 存档先写临时文件再整体替换，同一文件的写入排队执行。
- 交给模型的资料过长时，按内容精简并写明省略了什么，不在中间硬截断。

## 一次评测怎么跑

```
评价体系 + 数据源 + 输出 + 提示词
   → 制定或沿用评分细则（模型 1 次，可复用）
   → 逐样本评测（模型每条样本 1 次，并发，只列问题和等级）
   → 程序计分
   → 复核修正（模型 1 次，程序核对后重新计分）
   → 问题整合（模型 1 次）
   → 提示词策略（模型 1 次）
   → 报告与历史，可对比
```


## 快速开始

1. 安装 Python 3.9 或以上，Windows 安装时勾选 Add python.exe to PATH。
2. 双击 `启动EvalLab.bat`，浏览器会打开 `http://127.0.0.1:4174/index.html`。
3. 想新建评测，需要在页面右侧的「模型网关」里填入你自己的网关地址和 API Key。不配置时，仍可浏览内置的历史评测和报告。
